# Parque Nacional 3D

Inventario 3D del patrimonio escultórico del Parque Nacional Enrique Olaya Herrera (Bogotá).
Proyecto de Fotogrametría Digital — Ingeniería Catastral y Geodesia, Universidad Distrital Francisco José de Caldas.

- `index.html`: página con mapa interactivo (Leaflet) y fichas de cada obra.
- `modelos/`: modelos 3D en GLB (fotogrametría terrestre, Pix4D) y sus copias `.glb.js` para abrir la página sin servidor.
- `datos/`: capas geográficas (polígono del parque exportado desde QGIS).
